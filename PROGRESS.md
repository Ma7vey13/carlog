## Этап 1 — Каркас PWA и публикация: готово частично

Код, тесты и сборка готовы и проверены на GitHub. Приложение ещё не опубликовано: для этого владельцу нужно один раз включить GitHub Pages.

### Что сделано
- Проект на Vite 8 + React 19 + TypeScript 7, версии зависимостей зафиксированы точно.
- Навигация: Состояние · История · Входящие · Регламент · Ещё. На телефоне — нижняя панель, на широком экране — боковое меню. Адреса вида `#/history` работают офлайн и в установленном приложении.
- Пустые экраны с пояснением, что и на каком этапе там появится. Неизвестный адрес → «Страница не найдена» со ссылкой на главную.
- Светлая, тёмная и системная тема: переключатель в «Ещё», выбор сохраняется, нет вспышки при запуске. Цвет строки состояния Android совпадает с темой.
- PWA: манифест, иконки (синий спидометр, включая maskable для Android), работа без интернета, метка «офлайн» в шапке, подсказка «Приложение сохранено и будет открываться без интернета».
- Подсказка «Доступна новая версия» с кнопками «Обновить» и «Позже». При проверке нашлась и исправлена ошибка: при самом первом открытии кнопка «Обновить» ничего не делала (D-019).
- «Ещё»: сколько места занято, включено ли постоянное хранилище (запрашивается при первом запуске), версия и дата сборки.
- Content-Security-Policy: только свой сайт и `api.github.com`, без `unsafe-inline` и `unsafe-eval`.
- GitHub Actions: на каждый push — проверка типов, юнит-тесты, смоук-тесты, сборка; из `main` — публикация на Pages.
- Инструкции: `docs/02-github-pages.md` (включить Pages), `docs/03-install.md` (установка на Android и компьютер).

### Как проверить самому
1. Включите Pages по `docs/02-github-pages.md` и дождитесь зелёной галочки в **Actions**.
2. На компьютере: откройте https://ma7vey13.github.io/carlog/ в Chrome или Edge → установите по `docs/03-install.md` → пройдите по пяти разделам → в «Ещё» переключите тему.
3. На телефоне: откройте ту же ссылку в Chrome → дождитесь подсказки «Приложение сохранено…» → **⋮ → Установить приложение** → включите режим полёта → откройте «Бортжурнал» со значка.
Ожидаемый результат: приложение открывается по ссылке и со значка, без интернета показывает метку «офлайн» и все пять разделов.

### Тесты и сборка
- Юнит-тесты (Vitest): 13 пройдено, 0 упало — форматирование дат, километров, размеров и разбор адресов.
- Смоук-тесты (Playwright, 360 px и 1366 px): 15 пройдено, 0 упало, 1 пропущен намеренно. Тест обновления меняет общий `dist/sw.js` и поэтому гоняется только на одном размере. Проверяется: навигация без ошибок в консоли и без горизонтальной прокрутки, «страница не найдена», тема и её сохранение, хранилище и версия, CSP, манифест и иконки, работа офлайн, подсказка о новой версии и обновление по кнопке.
- Сборка: без ошибок; одно ожидаемое предупреждение про `theme-init.js` (D-021).
- GitHub Actions: задание тестов и сборки зелёное, 45 секунд. Публикация падает с «Ensure GitHub Pages has been enabled» — Pages ещё не включён.
- Вручную просмотрены скриншоты на 360 px и на десктопе в обеих темах; поправлены перенос подписи «Как в системе» → «Системная» и выравнивание заголовка на десктопе.

### Решения и отклонения от ТЗ
- D-019: обновление через `clientsClaim` и собственную перезагрузку.
- D-020: иконки рендерятся из SVG через Playwright, без отдельного пакета.
- D-021: тема — в `localStorage` (настройка устройства, не синхронизируется).
- D-022: точные версии зависимостей.
- D-023: CI закреплён на Ubuntu 24.04 — на новой Ubuntu 26 установка браузера для тестов шла 17 минут.
- D-024: постоянное хранилище запрашивается при первом запуске.
- Тег `stage-1` поставлю после первой успешной публикации, когда этап можно будет принять.

### Известные проблемы и ограничения
- На iPhone (Safari) не проверялось — в ТЗ только Android и компьютер.
- Подсказка «Позже» скрывает обновление до следующего запуска; новая версия включится, когда все окна приложения будут закрыты.

### Нужно от владельца
- Действия руками: включить GitHub Pages и перезапустить публикацию — `docs/02-github-pages.md`. Затем установить приложение на телефон и компьютер — `docs/03-install.md`.
- Вопросы: нет.
