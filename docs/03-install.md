# Шаг 3. Установить приложение на телефон и компьютер

Приложение одно и то же на всех устройствах: **https://ma7vey13.github.io/carlog/**. После установки оно открывается с главного экрана как обычное приложение и работает без интернета.

## Android (Chrome)

1. Откройте ссылку в **Chrome**.
2. Подождите несколько секунд: внизу появится подсказка **«Приложение сохранено и будет открываться без интернета»** — нажмите **Понятно**.
3. Нажмите меню **⋮** в правом верхнем углу → **Установить приложение** (в некоторых версиях — **Добавить на главный экран** → **Установить**).
4. Подтвердите **Установить**. На главном экране появится значок «Бортжурнал» — синий спидометр.

Проверка офлайн-режима: включите режим полёта и откройте «Бортжурнал» со значка. Приложение откроется, а в шапке появится метка **офлайн**.

## Компьютер (Chrome или Edge)

1. Откройте ссылку.
2. В адресной строке справа нажмите значок **Установить** (монитор со стрелкой) → **Установить**.
   Или меню **⋮** → **Трансляция, сохранение и отправка** → **Установить страницу как приложение** (названия пунктов немного отличаются в разных версиях).
3. «Бортжурнал» откроется в отдельном окне и появится в меню «Пуск».

## Обновления

Когда выходит новая версия, приложение скачивает её в фоне и показывает внизу **«Доступна новая версия приложения»**:

- **Обновить** — перезапустит приложение с новой версией;
- **Позже** — подсказка скроется, обновление применится при следующем запуске после закрытия всех окон приложения.

Номер версии виден в разделе **Ещё → О приложении**.

## Постоянное хранилище

В разделе **Ещё → Хранилище на этом устройстве** видно, сколько места занято, и включено ли постоянное хранилище. Оно защищает данные от автоматической очистки, когда на телефоне кончается место. Chrome обычно включает его сам, когда приложение установлено; если там написано «не включено», нажмите **Запросить у браузера**.
