# Три способа внести документ

Документ — это заказ-наряд, акт выполненных работ, товарная накладная или чек. Приложение превращает его в визит: дата, пробег, сервис, строки работ и запчастей с ценами, итоги.

## Сначала — скан

1. **Входящие** → **Сфотографировать** (камера) или **Выбрать фото или PDF**.
2. Всё, что выбрано за один раз, — один документ. Многостраничный акт снимайте подряд в одном заходе; забытую страницу добавит **Ещё → Добавить страницу** на экране черновика.
3. Если в одном PDF лежат разные документы (например, архив накладных), на экране черновика нажмите **Это разные документы — разделить по страницам**.

Сканы сжимаются и хранятся на устройстве, на GitHub уходят только зашифрованными.

## А. Claude Code — пачкой на компьютере

Удобно для архива и когда документов много. Подробно — в [инструкции по Claude Code](05-claude-code.md). Коротко:

1. На телефоне: сканы во **Входящих** → **Ещё → Отправить**.
2. На компьютере в папке проекта: команда **/parse-scans** в Claude Code. Пароль данных вводите только сами, в окне браузера, которое откроет команда.
3. В приложении: **Подтянуть** → черновики «Готов к проверке» → проверить и сохранить.

## Б. Любой чат-ИИ — с телефона

1. Откройте черновик во **Входящих** → **Скопировать промпт**.
2. Откройте чат (Gemini, Claude и т. п.), вставьте промпт.
3. Вернитесь в приложение → **Открыть скан** → поделитесь страницами в чат (или прикрепите их из «Загрузок»).
4. Скопируйте ответ чата целиком и вставьте в поле **Вставить результат** → **Проверить и продолжить**. Приложение само найдёт JSON в ответе; если чат ошибся в формате, оно скажет, что исправить.

На скане есть ваши ФИО, телефон и госномер. Для распознавания они не нужны — можно закрыть их пальцем на фото или обрезать. Как отключить сохранение чатов в Gemini — **Ещё → Распознавание через чат-ИИ**.

## В. Вручную

**История → Добавить визит**. Удобные приёмы:

- **Вставить шаблон** — готовые строки для частых работ (ТО двигателя, тормоза и др.), останется вписать цены.
- **Скопировать прошлый визит** — тот же сервис и строки, новая дата.
- Названия подсказываются из истории; узел подбирается по словам названия.
- Для черновика со сканом — **Ввести вручную** на экране черновика: скан будет рядом.

## Экран проверки

Слева (или на вкладке **Скан** на телефоне) — скан, справа — данные. Автопроверки подсвечивают:

1. сумма строки не равна «кол-во × цена»;
2. итоги документа не сходятся со строками;
3. похожий документ уже есть в истории (тот же номер или акт к тому же заказ-наряду) — можно **заменить строки** в существующем визите;
4. в документе нет пробега — можно **прикрепить** его к визиту рядом по дате;
5. пробег меньше, чем в более раннем визите;
6. работа есть, а запчасти к ней нет (масло, фильтр) — возможно, это ваша запчасть: **Добавить как запчасть клиента**;
7. дата странная (в будущем или раньше всей истории).

Каждое замечание нужно поправить или подтвердить — только тогда станет доступно **Сохранить визит**. Если поправили название или узел строки, можно отметить **Запомнить для похожих строк** — в следующий раз приложение сделает так же само.
