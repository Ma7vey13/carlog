# Резервная копия, смена пароля, хранилище

## Сохранить резервную копию

**Ещё → Резервная копия → Сохранить резервную копию.** Получится файл `carlog-backup-ГГГГ-ММ-ДД.zip` в «Загрузках»: все записи (визиты, регламент, самопроверка, ОСАГО и т. д.) и все сканы.

- Сканы, которых на этом устройстве нет (на телефоне они скачиваются только при просмотре), приложение сначала скачает с GitHub — нужны интернет и пароль данных. Если что-то не скачалось, оно напишет, сколько сканов не попало в копию.
- **Файл не зашифрован.** В нём ваши документы, ФИО, номер полиса. Храните его на своём компьютере или флешке; не отправляйте в мессенджеры и облака без шифрования.
- Делайте копию раз в месяц, после ввода большого архива и перед сменой телефона.

## Восстановить из копии

**Ещё → Резервная копия → Выбрать файл копии** → **Восстановить**.

Записи из копии **сливаются** с тем, что есть на устройстве: у каждой записи остаётся более новая версия, ничего не удаляется. Поэтому восстанавливать безопасно даже на устройство с данными, а повторное восстановление той же копии ничего не меняет. Каждый скан проверяется по контрольной сумме; повреждённые пропускаются, и приложение об этом пишет.

Чтобы восстановленное попало на другие устройства, нажмите **Отправить**.

### Новый телефон

Проще всего — без копии: установите приложение ([установка](03-install.md)) и подключите синхронизацию как второе устройство ([синхронизация, шаг 3](04-sync.md)). Все данные подтянутся с GitHub.

### GitHub недоступен или репозиторий данных потерян

1. Установите приложение и восстановите последнюю копию.
2. Создайте новый пустой приватный репозиторий `carlog-data` ([репозитории](01-github-repos.md)).
3. Настройте синхронизацию как на первом устройстве ([синхронизация, шаг 2](04-sync.md)) — все данные и сканы уйдут в новый репозиторий.

### Забыли пароль данных

Копия не зашифрована, поэтому с ней пароль не нужен: восстановите её на устройстве и пройдите шаги из раздела выше с новым паролем.

## Сменить пароль

**Ещё → Настройки синхронизации → Сменить пароль.** Введите текущий пароль и дважды новый.

- Все файлы на GitHub перешифровываются новым паролем и записываются одним коммитом. Нужен интернет; не закрывайте приложение, пока не появится «Пароль сменён».
- Сохраните новый пароль в менеджере паролей до того, как нажмёте кнопку. Забытый пароль = потерянные данные на GitHub.

### На другом устройстве

При следующем **Отправить** или **Подтянуть** приложение напишет «Пароль сменили на другом устройстве» → **Ввести пароль** → новый пароль → **Открыть**.

Если на этом устройстве пароль не был запомнен, приложение попросит ещё и **старый пароль** — один раз: им зашифрован токен GitHub на этом устройстве, после этого токен перешифруется новым паролем.

Если при обычном вводе пароля приложение пишет «Неверный пароль», а вы уверены в новом — нажмите **Пароль меняли на другом устройстве?**.

## Хранилище

**Ещё → Хранилище** показывает:

- сколько места занято в браузере и включено ли постоянное хранилище — оно защищает данные от автоматической очистки, когда на телефоне кончается место; если «не включено», нажмите **Запросить у браузера**;
- сколько визитов, документов, черновиков и сканов на устройстве, сколько сканов есть только на GitHub.

**Освободить место** удаляет с устройства копии сканов, которые уже отправлены на GitHub, и файлы удалённых документов. Записи не трогаются; скан скачается снова, когда вы его откроете (нужны интернет и пароль). Если не уверены, что GitHub доступен, сначала сохраните резервную копию.
