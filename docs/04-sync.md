# Шаг 4. Синхронизация телефона и компьютера

Данные живут на каждом устройстве отдельно и обмениваются через приватный репозиторий `carlog-data` кнопками **Отправить** и **Подтянуть**. Всё, что уходит на GitHub, шифруется вашим паролем прямо на устройстве. В репозитории читаем только `vault.json`, и в нём нет секретов: только параметры шифрования.

Понадобится 15 минут: токен GitHub, затем настройка на телефоне, затем на компьютере.

## Шаг 1. Создать токен GitHub

Токен — это «ключ» приложения к одному репозиторию `carlog-data`. Удобнее сделать отдельный токен для каждого устройства: тогда потерянный телефон можно отключить, не трогая компьютер.

1. Откройте https://github.com и войдите.
2. Нажмите на аватар в правом верхнем углу → **Settings**.
3. В самом низу меню слева — **Developer settings**.
4. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
5. Заполните:
   - **Token name** — например, `Бортжурнал — телефон`;
   - **Expiration** — срок действия. Удобно **Custom** на год вперёд. Когда срок кончится, приложение напишет «Токен истёк или неверен» — сделаете новый по этой же инструкции;
   - **Resource owner** — ваш аккаунт;
   - **Repository access** → **Only select repositories** → в списке выберите **carlog-data**. Только его: токен не должен видеть другие репозитории.
6. В блоке **Permissions** откройте **Repository permissions** → строка **Contents** → выберите **Read and write**. Строка **Metadata: Read-only** включится сама. Остальное не трогайте.
7. Нажмите **Generate token** (и ещё раз **Generate token** в окне подтверждения).
8. Скопируйте токен — он начинается с `github_pat_`. GitHub покажет его только один раз. Если закрыли страницу, не скопировав, — удалите этот токен и создайте новый.

Токен никуда не записывайте и никому не отправляйте. Приложение хранит его только на устройстве, зашифрованным вашим паролем.

## Шаг 2. Первое устройство (например, телефон)

1. Откройте приложение → **Ещё** → **Настроить синхронизацию**.
2. **Репозиторий данных** — уже подставлен (`Ma7vey13/carlog-data`). **Токен GitHub** — вставьте. **Имя устройства** — «Телефон».
3. Нажмите **Проверить доступ**. Приложение убедится, что репозиторий приватный и токен может в него писать.
4. Придумайте **пароль данных** — не короче 12 символов. Удобно взять 4–5 случайных слов.
5. **Сразу сохраните пароль в менеджере паролей.** Забытый пароль = потерянные данные на GitHub: восстановить его не может никто.
6. Отметьте **Я сохранил пароль в менеджере паролей**. Галочка **Запомнить на этом устройстве** избавит от ввода пароля при каждой синхронизации — включайте её только на своих устройствах.
7. **Создать хранилище и отправить данные** — первое создание ключа занимает пару секунд.

## Шаг 3. Второе устройство (компьютер)

1. Создайте для компьютера ещё один токен — шаг 1.
2. В приложении на компьютере: **Ещё** → **Настроить синхронизацию** → тот же репозиторий, новый токен, имя «Компьютер» → **Проверить доступ**.
3. Приложение увидит, что данные уже есть, и попросит **тот же пароль**, что на телефоне → **Подключиться**. Данные с телефона подтянутся.
4. Если на компьютере до этого что-то вводили, нажмите **Отправить** — эти записи уйдут на телефон.

## Каждый день

- Ввели или поправили что-то → **Ещё** → **Отправить**.
- На другом устройстве → **Подтянуть**. Если на GitHub есть новые данные, приложение само предложит это при запуске — плашкой «На GitHub есть новые данные» с кнопкой **Подтянуть**. Само оно ничего не применяет.
- Меняли данные на обоих устройствах, не синхронизируя? Ничего не потеряется: записи сливаются, побеждает более поздняя правка каждой отдельной записи. **Отправить** сначала подтянет чужие изменения, потом отправит свои.
- В **Ещё** видно: когда последний раз отправляли и подтягивали, сколько изменений ещё не отправлено, как называется это устройство.
- Сканы на телефоне скачиваются, только когда вы их открываете — так экономится место. На компьютере можно включить **Скачивать все сканы при «Подтянуть»** в настройках синхронизации.

## Если токен истёк

Приложение покажет «Токен истёк или неверен». Данные на устройстве в порядке.

1. Создайте новый токен — шаг 1.
2. В приложении нажмите **Ввести новый токен** прямо в сообщении об ошибке (или **Ещё** → **Настройки синхронизации** → **Заменить токен**) и вставьте его.
3. Нажмите **Отправить** или **Подтянуть** ещё раз.
4. Старый токен удалите на GitHub: **Settings** → **Developer settings** → **Fine-grained tokens** → токен → **Delete**.

## Сменить пароль

**Ещё** → **Настройки синхронизации** → **Сменить пароль**: все файлы на GitHub перешифруются новым паролем одним коммитом. На другом устройстве при следующей синхронизации приложение напишет «Пароль сменили на другом устройстве» и попросит новый пароль. Подробно — [Сменить пароль](07-backup.md#сменить-пароль).

## Если забыли пароль

Зашифрованные данные на GitHub без пароля не открыть — это и есть защита. Но данные на ваших устройствах остаются.

Если устройства с данными под рукой нет, но есть [резервная копия](07-backup.md#забыли-пароль-данных) — восстановите её (она не зашифрована) и пройдите шаги ниже на этом устройстве.

1. На устройстве с самыми полными данными: **Ещё** → **Настройки синхронизации** → **Отключить синхронизацию здесь**. Данные на устройстве не удаляются.
2. Очистите репозиторий `carlog-data` на GitHub: удалите его и создайте заново пустым приватным (см. [шаг 1 инструкции по репозиториям](01-github-repos.md)).
3. Настройте синхронизацию заново (шаг 2) с новым паролем, затем подключите второе устройство (шаг 3).

## Что лежит в carlog-data

| Файл | Что внутри | Читаемый? |
| --- | --- | --- |
| `vault.json` | версия формата, соль и число итераций для ключа, зашифрованная проверочная строка | да, но секретов нет |
| `data/snapshot.enc` | все записи: визиты, документы, строки, пробег, справочники, черновики | нет, AES-GCM 256 |
| `scans/<хеш>.enc` | сканы, каждый отдельным файлом | нет |
| `drafts/<id>.enc` | результаты распознавания от Claude Code (этап 5) | нет |

## Безопасность

- `carlog-data` должен оставаться **приватным**. Если сделать его публичным, приложение откажется с ним работать.
- Токен — только к `carlog-data` и только с правом Contents.
- Включите двухфакторную аутентификацию в аккаунте GitHub: **Settings** → **Password and authentication**.
- Пароль не хранится нигде, кроме вашей памяти и менеджера паролей. «Запомнить на этом устройстве» хранит не пароль, а ключ, который нельзя извлечь из браузера.
