# Шаг 2. Включить GitHub Pages

GitHub Pages публикует приложение по адресу **https://ma7vey13.github.io/carlog/**. Код собирается и проверяется автоматически при каждой отправке в `main` (вкладка **Actions**), а Pages нужно один раз включить руками.

## 1. Включить Pages

1. Откройте https://github.com/Ma7vey13/carlog.
2. Вверху нажмите **Settings** (шестерёнка).
3. В меню слева, в разделе **Code and automation**, выберите **Pages**.
4. В блоке **Build and deployment** найдите **Source** и выберите **GitHub Actions**. Больше ничего менять не нужно, кнопки «Сохранить» здесь нет — выбор применяется сразу.

## 2. Запустить публикацию

Первая публикация, сделанная до включения Pages, завершилась ошибкой — это нормально. Запустите её заново:

1. Вверху нажмите **Actions**.
2. Слева выберите **Test and deploy**.
3. Справа нажмите **Run workflow** → в появившемся окне снова **Run workflow** (ветка `main`).
4. Подождите 3–5 минут, пока у запуска не появится зелёная галочка. Шаг **deploy** покажет ссылку на сайт.

## 3. Проверить

Откройте https://ma7vey13.github.io/carlog/ — должен открыться «Бортжурнал» с пятью разделами внизу экрана (на телефоне) или слева (на компьютере).

## Если что-то пошло не так

- **Красный крестик у запуска.** Нажмите на запуск → на шаг с крестиком: там текст ошибки. Если упали тесты, внизу страницы запуска будет архив `playwright-report` с подробностями. Пришлите Claude Code ссылку на запуск.
- **Ошибка «Get Pages site failed» или «Not Found» на шаге deploy.** Pages не включён или выбран другой источник: повторите раздел 1.
- **Сайт открывается, но старая версия.** Приложение кеширует себя для работы без интернета. Новая версия скачается в фоне, и внизу появится подсказка **«Доступна новая версия приложения»** → нажмите **Обновить**.
