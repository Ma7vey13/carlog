# Руководство владельца

«Бортжурнал» — журнал обслуживания Santa Fe: все визиты в сервис со сканами документов, что и когда пора менять, самопроверка и сроки ОСАГО. Данные живут на ваших устройствах и синхронизируются через ваш приватный репозиторий GitHub в зашифрованном виде.

Адрес приложения: **https://ma7vey13.github.io/carlog/**. Всё руководство есть и в самом приложении: **Ещё → Руководство**.

## Первый запуск — по порядку

Шаги 1 и 2 уже сделаны при разработке; их стоит повторять только при переезде на новый аккаунт GitHub.

1. [Репозитории GitHub](01-github-repos.md) — публичный `carlog` с приложением и приватный `carlog-data` для данных.
2. [Публикация сайта](02-github-pages.md) — GitHub Pages.
3. [Установка на телефон и компьютер](03-install.md) — значок на главном экране, работа без интернета.
4. [Синхронизация](04-sync.md) — токен, пароль данных, подключение второго устройства.
5. [Резервная копия](07-backup.md) — сохраните первую копию сразу после того, как внесли архив документов.

## Как внести документ

Три способа — подробно в [инструкции по распознаванию](06-recognition.md):

| Способ | Когда удобен | Что нужно |
| --- | --- | --- |
| А. Claude Code | много документов сразу, архив | компьютер и подписка на Claude |
| Б. Чат-ИИ | один-два документа с телефона | любой чат: Gemini, Claude и т. п. |
| В. Вручную | короткий чек, своя работа без документа | ничего |

Любой способ заканчивается экраном проверки: приложение показывает скан рядом с данными и подсвечивает подозрительное. В историю попадает только то, что вы подтвердили.

## Каждый день

- **Состояние** — главный экран: пробег, что пора менять, документы со сроком, самопроверка. Подробнее — [Главный экран, регламент, самопроверка](08-everyday.md).
- После визита в сервис: сфотографируйте документы во **Входящих**, распознайте одним из способов, проверьте и сохраните.
- Заправились или просто посмотрели на одометр — впишите пробег в поле **Обновить пробег** на главном экране: от него считаются сроки.
- Ввели что-то на одном устройстве → **Ещё → Отправить**; на другом → **Подтянуть**.
- Раз в месяц и перед сменой телефона — **Ещё → Резервная копия → Сохранить**.

## Где что лежит

| Раздел | Что там |
| --- | --- |
| Состояние | пробег, «Пора заняться», ОСАГО, самопроверка, синхронизация |
| История | все визиты, поиск по названию и узлу, ручной ввод визита |
| Входящие | новые сканы и черновики распознавания |
| Регламент | пункты ТО с интервалами |
| Ещё | синхронизация, справочники, расчёт сроков, резервная копия, хранилище, руководство |

## Если что-то пошло не так

| Что случилось | Что делать |
| --- | --- |
| «Токен истёк или неверен» | [Если токен истёк](04-sync.md#если-токен-истёк) |
| Пароль сменили на другом устройстве | [На другом устройстве](07-backup.md#на-другом-устройстве) |
| Забыли пароль | [Если забыли пароль](04-sync.md#если-забыли-пароль) |
| Новый телефон | установите приложение и подключите синхронизацию — данные подтянутся; без GitHub — [восстановление из копии](07-backup.md#восстановить-из-копии) |
| Распознавание ошиблось | исправьте на экране проверки или в визите: **История → визит → Изменить** |
| Кончается место на телефоне | [Хранилище](07-backup.md#хранилище) — освободить место от копий сканов |
