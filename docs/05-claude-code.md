# Шаг 5. Распознавание через Claude Code

Самый быстрый способ разобрать стопку накладных, пока есть подписка на Claude, и без VPN на телефоне. На телефоне вы только фотографируете, распознаёт Claude Code на компьютере, а вы проверяете и сохраняете каждый документ в приложении, как обычно. Без подписки работают распознавание через чат и ручной ввод — ничего не теряется.

## 1. Добавить сканы

1. В приложении: **Входящие** → **Сфотографировать** или **Выбрать фото или PDF**.
   - Несколько фото, выбранных разом, — это страницы одного документа.
   - Если в одном PDF несколько разных документов — откройте черновик и нажмите **Это разные документы — разделить по страницам**.
2. Больше ничего: при включённой автосинхронизации сканы сами уходят в `carlog-data` зашифрованными. Если автосинхронизация выключена — **Ещё** → **Отправить**.

## 2. Запустить /parse-scans

1. На компьютере откройте Claude Code в папке проекта `carlog` (там, где лежат `SPEC.md` и `private/`).
2. Введите `/parse-scans`.
3. Claude запустит `npm run inbox:session`:
   - при первом запуске Git может попросить войти в GitHub — в окне **Connect to GitHub** нажмите **Sign in with your browser**;
   - откроется страница **Пароль данных Бортжурнала** — введите пароль синхронизации **один раз**. Страница открыта только на вашем компьютере, пароль уходит прямо в программу, хранится только в её памяти до конца сессии и нигде не сохраняется.
4. Claude прочитает сканы, запишет черновики и проверит их командой `npm run inbox:check`.
5. Сессия сама зашифрует черновики, отправит их в `carlog-data` и удалит расшифрованные сканы с компьютера — второй раз пароль не нужен.

**Claude никогда не должен просить пароль в чате.** Если попросит — не вводите, а напишите ему, что пароль вводится только на странице в браузере.

## 3. Проверить и сохранить

1. На телефоне черновики появятся во **Входящих** сами — при открытии приложения, при возврате в него или в течение 5 минут (автосинхронизация). Если автосинхронизация выключена — **Ещё** → **Подтянуть**.
2. Черновики стали «Готов к проверке».
3. Откройте каждый: скан рядом с данными, автопроверки, замечания Claude из раздела «Заметки распознавателя». Исправьте, подтвердите замечания → **Сохранить визит**.

## Если что-то пошло не так

- **«Неверный пароль»** — повторите команду; пароль тот же, что для синхронизации.
- **«Скан ещё не отправлен с телефона»** — откройте приложение на устройстве, где добавляли скан, дождитесь синхронизации (или **Ещё** → **Отправить**) и повторите.
- **«Черновиков, ждущих распознавания, нет»** — сканы не отправлены, или черновики уже распознаны и ждут «Подтянуть» в приложении.
- **Работа прервалась** — сессия удаляет расшифрованные сканы сама (через 3 часа ожидания тоже). Если папка `private/inbox` всё же осталась, повторите `/parse-scans` или удалите её вручную.
- Команды можно запускать и самому в терминале в папке проекта: `npm run inbox:session` (всё за один пароль) или по шагам — `npm run inbox:pull`, `npm run inbox:check`, `npm run inbox:push`.
