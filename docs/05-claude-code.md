# Шаг 5. Распознавание через Claude Code

Самый быстрый способ разобрать стопку накладных, пока есть подписка на Claude. Сканы добавляются в приложении, распознаёт их Claude Code на компьютере, а вы проверяете и сохраняете каждый документ в приложении, как обычно. Без подписки работают распознавание через чат и ручной ввод — ничего не теряется.

## 1. Добавить сканы

1. В приложении: **Входящие** → **Сфотографировать** или **Выбрать фото или PDF**.
   - Несколько фото, выбранных разом, — это страницы одного документа.
   - Если в одном PDF несколько разных документов — откройте черновик и нажмите **Это разные документы — разделить по страницам**.
2. **Ещё** → **Отправить**. Сканы уходят в `carlog-data` зашифрованными.

## 2. Запустить /parse-scans

1. На компьютере откройте Claude Code в папке проекта `carlog` (там, где лежат `SPEC.md` и `private/`).
2. Введите `/parse-scans`.
3. Claude запустит `npm run inbox:pull`:
   - при первом запуске Git может попросить войти в GitHub — в окне **Connect to GitHub** нажмите **Sign in with your browser**;
   - откроется страница **Пароль данных Бортжурнала** — введите пароль синхронизации. Страница открыта только на вашем компьютере, пароль уходит прямо в программу и нигде не сохраняется.
4. Claude прочитает сканы и запишет черновики, затем проверит их командой `npm run inbox:check`.
5. Claude запустит `npm run inbox:push` — ещё раз введите пароль на открывшейся странице. Черновики зашифруются и уйдут в `carlog-data`, а расшифрованные сканы удалятся с компьютера.

**Claude никогда не должен просить пароль в чате.** Если попросит — не вводите, а напишите ему, что пароль вводится только на странице в браузере.

## 3. Проверить и сохранить

1. В приложении (на телефоне или компьютере): **Ещё** → **Подтянуть**, или кнопка **Подтянуть** на плашке «На GitHub есть новые данные».
2. **Входящие** — черновики стали «Готов к проверке».
3. Откройте каждый: скан рядом с данными, автопроверки, замечания Claude из раздела «Заметки распознавателя». Исправьте, подтвердите замечания → **Сохранить визит**.

## Если что-то пошло не так

- **«Неверный пароль»** — повторите команду; пароль тот же, что для синхронизации.
- **«Скан ещё не отправлен с телефона»** — на устройстве, где добавляли скан, нажмите **Отправить** и повторите.
- **«Черновиков, ждущих распознавания, нет»** — сканы не отправлены, или черновики уже распознаны и ждут «Подтянуть» в приложении.
- **Работа прервалась** — расшифрованные сканы остались в папке `private/inbox` на компьютере. Повторите `/parse-scans` (готовые черновики не пропадут) или удалите эту папку вручную.
- Команды можно запускать и самому в терминале в папке проекта: `npm run inbox:pull`, `npm run inbox:check`, `npm run inbox:push`.
