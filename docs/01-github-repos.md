# Шаг 1. Создать репозитории на GitHub

Нужны два репозитория:

- **`carlog`** — публичный. Здесь только код приложения; из него GitHub Pages публикует сайт.
- **`carlog-data`** — приватный. Здесь будут лежать ваши данные, но только в зашифрованном виде.

Займёт 5–10 минут. Названия кнопок даны так, как они написаны в интерфейсе GitHub (по-английски).

## 1. Войти в GitHub

1. Откройте https://github.com и нажмите **Sign in**.
2. Если аккаунта нет — **Sign up**, пройдите регистрацию и подтвердите почту.

## 2. Создать публичный репозиторий `carlog`

1. В правом верхнем углу нажмите **+** → **New repository**.
2. **Owner** — ваш аккаунт.
3. **Repository name** — `carlog`.
4. **Description** — можно оставить пустым.
5. Видимость — **Public**.
6. Ничего не добавляйте: переключатель **Add README** выключен, **Add .gitignore** — *No .gitignore*, **Add license** — *No license*. Код и `.gitignore` уже подготовлены на компьютере, лишние файлы на GitHub помешают первой отправке.
7. Нажмите **Create repository**.

Открывшуюся страницу с подсказками можно просто закрыть.

## 3. Создать приватный репозиторий `carlog-data`

1. Снова **+** → **New repository**.
2. **Repository name** — `carlog-data`.
3. Видимость — **Private**. Это важно: проверьте, что выбрано именно Private.
4. Тоже ничего не добавляйте: без README, без .gitignore, без лицензии. README был бы единственным читаемым файлом в хранилище данных, а там должны лежать только зашифрованные файлы. Первый файл туда запишет само приложение на этапе 4.
5. Нажмите **Create repository**.

## 4. Скрыть свою почту в коммитах

Имя и почта автора видны в каждом коммите публичного репозитория. Чтобы там не было вашей личной почты:

1. Нажмите на аватар в правом верхнем углу → **Settings**.
2. Слева выберите **Emails**.
3. Включите галочку **Keep my email addresses private**.
4. Под ней появится служебный адрес вида `12345678+логин@users.noreply.github.com` — скопируйте его.
5. По желанию включите **Block command line pushes that expose my email** — тогда GitHub не примет коммит с личной почтой даже случайно.

## 5. Сообщить Claude Code

Напишите в чат:

- ваш логин на GitHub;
- служебный адрес из шага 4;
- какое имя ставить автором коммитов (псевдоним, например `Noir`, а не ФИО).

После этого Claude Code сделает первый коммит и отправит код в `carlog`. При первой отправке Git откроет окно **Connect to GitHub** — нажмите **Sign in with your browser**, затем в браузере **Authorize git-ecosystem**. Это одноразово: дальше Git запомнит вход.
